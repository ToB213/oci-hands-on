# OCI Hands-on

A hands-on repository for learning Oracle Cloud Infrastructure (OCI) and Terraform.

This repository follows the official OCI beginner tutorials, recreating the infrastructure using Terraform instead of manually configuring resources through the OCI Console.

## Reference

- [Oracle Cloud Infrastructure - Beginner Tutorials](https://oracle-japan.github.io/ocitutorials/beginners/)

## Tools

- Oracle Cloud Infrastructure (OCI)
- Terraform
- Nix Flakes
- OCI CLI
